# Admin kalan doğrulamalar ve düzeltmeler

3 Ekim 2026 güncellemesi. Bu raporun kabul sonuçları admin paneline aittir; Windows tekrarlarının ardından native Ubuntu/WSL2 kurulumu da tamamlandı. Öğretmen panelinin gerçek tarayıcı/API, sayfa/sekme ve çıktı denetimi [ayrı rapordadır](../teacher-audit/verification.md); doğrulanmış sorunları ve sınanmayan işlem varyantları vardır, bütün öğretmen davranışları kabul edilmemiştir. Bu ek rapor, [önceki admin onarımlarını](remaining-repairs-verification.md) tamamlayan Excel, yazdırma, erişilebilirlik ve gerçek hibrit kurulum çalışmasını kaydeder. Bekleyen veya erişilemeyen kontroller başarılı kabul edilmez.

Son tamamlanmış birleşik Node koşusu **31 testte 30 geçti / 1 başarısız**, exit **1**, toplam **108,821 saniye**. Başlangıç testinde native PNG geçti; API için 30 saniyede CSRF yanıtı alınamadı (test **50,352 saniye**). Lifecycle kaydı spawned=true/exited=false/closed=false ve yalnız pnpm başlangıç çıktısı gösterir; belirli ürün nedenini kanıtlamaz. Son ayrı native-only tekrar API bütçesi 120 saniyeyle **1/1 geçti**, exit **0**; test **71,936 saniye**, toplam **72,608 saniye**. Native PNG/CSRF/dosya assertion'ları aynı kaldı. Bu ayrı tekrar, birleşik koşuyu 31/31 yapmaz. Önceki 1/1 (17,84 saniye) geçiş ve gerçek BAT API admin girişi korunur. Daha önceki birleşik koşu ayrıca **INCOMPLETE** idi: 2 geçti/1 hata, kalanlar çalışmadı; stalled koşu Ctrl+C exit 1 ile kapandı, startup testi 110,48 saniyede CSRF alamadı/boş çıktı yakaladı. Bu kayıtlar tek başarılı toplam olarak birleştirilmez. [Sansürlenmiş kaynak-test özeti](evidence/closure/hybrid/source-test-summary.json).

### HY06 / kritik — derlenen API açılmıyor

Yedinci temiz terminal kurulumu sihirbazın bütün adımlarını tamamladıktan sonra `node dist/index.cjs` çalıştırıldı. Beklenen davranış, seçili API portunda başlatma ve yeni admin ile girişti. Gerçek davranış: Sharp 0.35.5'in `createRequire(import.meta.url)` çağrısı CJS bundle içinde `undefined` alıp `ERR_INVALID_ARG_VALUE` ile süreci kapattı; girişe ulaşılamadı. Kod kanıtı derlenen dosyada `var import_meta = {};` ve ardından `createRequire(import_meta.url)`; kurulumun başarılı migration sonucu API'nin çalıştığı anlamına gelmedi.

Mevcut CJS build komutunda Sharp native bağımlılık olarak dışarıda bırakıldı; [Sharp'ın resmi esbuild talimatı](https://sharp.pixelplumbing.com/install/#bundlers) da `--external:sharp` kullanır. Paket sürümleri değişmedi. Kabul kriteri: gerçek paket komutuyla derlenen API izole veritabanında açılır, CSRF yanıtı ve yeni admin API/UI girişi çalışır. Üretim başlangıç entegrasyonu **1/1 geçti**; son aynı-kod taze terminal/BAT/Git SH kurulum ve API/UI girişleri 3/3 geçti. Harness ayrıca README/systemd talimatındaki `pnpm --filter quiz-master-server start` komutunu kullanır; önceki doğrudan Node başlangıcı pnpm'in native modül çözümlemesi yerine sayılmaz.
